# 🍠 고구마마켓

당근마켓 스타일 중고거래 웹사이트 (Next.js + Supabase 학습용 프로젝트)

## 개발 단계
- [x] 1단계: 회원가입 / 로그인 / 로그아웃
- [x] 2단계: 판매글 CRUD (등록 / 목록 / 상세 / 수정 / 삭제, 사진 제외)
- [x] 3단계: 판매글 사진 업로드 (최대 5장)
- [x] 4단계: 좋아요 / 댓글

## 실행 방법
```bash
npm install
cp .env.example .env.local   # Supabase URL, publishable key 입력
npm run dev
```
http://localhost:3000 에서 확인
